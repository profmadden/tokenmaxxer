# tokenmaxxer
An AI-powered coding agent that wastes API tokens so that you can climb to the top of the developer leaderboard in your company.

Just kidding.  Are we seriously doing this?  I'm sure there's someone who has already done this, with an agent pinging Claude constantly, running up the bill so that the execs think they're "really productive."  It's not unlike counting the lines of code produced -- sometimes less is more.

There are all kinds of great libraries and frameworks available.  Oceans of carefully designed and debugged software, engineered for efficiency, reuse, flexibility.  IMO, you should write code only for things that don't exist (and are thus not in the training data).  If you're using a coding agent to implement the functionality of some library routine, you've lost the plot.
